# SER File Parser

## Goal

Create a SER file parser in Swift.  
The library should provide access to file metadata, frame information, etc, as well as convenience to create playable movie files on macOS.  
This can be done either by providing access to frame data, as images, or by directly encoding frame data as movie, using Apple's public frameworks. Maybe even both for maximum flexibility.
 
If possible and suitable, follow the architecture, conventions, and organization of the SwiftFITS project: https://github.com/macmade/SwiftFITS.git

Include complete and broad unit tests, just as SwiftFITS.  
Test files can be provided on demand.

The SwiftFITS repository is checked out in the directory above this repository.  
Make sure to read and understand how the project is structured and replicate as closely as possible when suitable.  
Do not reference any absolute file paths from SwiftFITS.

## References:
